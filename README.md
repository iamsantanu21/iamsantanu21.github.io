# Santanu Mondal — Portfolio

My personal portfolio website.

🌐 **Live site:** https://iamsantanu21.github.io

## About

A modern, responsive single-page portfolio built with plain HTML, CSS, and JavaScript — no frameworks, no build step. The entire site is a single self-contained `index.html` file (the profile photo is embedded), hosted on GitHub Pages.

**Features**
- Light / dark theme with a toggle (remembers your choice)
- Responsive layout for phone, tablet, and desktop
- Animated hero, filterable publications, and project cards
- Sections: About · Education · Publications · Projects · Skills · Activities · Contact

## Tech

`HTML` · `CSS` · `JavaScript` · `GitHub Pages`
