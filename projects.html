Projects (Selected Work)

Open-source projects spanning blockchain, zero-knowledge cryptography, Edge AI, ML security, and distributed systems.

Blockchain · Thesis

Multiple Identity Management of IoT Devices

A Hyperledger Fabric permissioned-blockchain system for managing multiple IoT device identities. JavaScript chaincode for identity registration and asset transfer, a Fabric Gateway SDK client, and network monitoring via Hyperledger Explorer.

ZK Cryptography · Hackathon

One-Human-One-Vote

A privacy-preserving, decentralized voting dApp built at the IIT Madras (CyStar) Winter School Hackathon. Solidity smart contracts with Merkle-tree eligibility commitments, zero-knowledge membership proofs, and nullifiers guaranteeing anonymity without linking votes to voters.

SolidityZero-KnowledgeMerkle Trees
Ethereum · Smart Contracts

Decentralized Voting DApp

An Ethereum voting smart contract (Solidity, Hardhat, Ethers.js) supporting multiple time-bound elections, one-vote-per-address enforcement, and real-time tallying — deployed and verified on the Sepolia testnet via Alchemy RPC with event logging and admin access controls.

SolidityHardhatEthers.jsSepolia
ML Security · NLP

MalURLX — Malicious URL Detection

An end-to-end ML system detecting malicious URLs from lexical and character-level TF-IDF features with a LightGBM classifier (~95–98% accuracy), served through a FastAPI/Uvicorn REST API and shipped with a companion Chrome extension for real-time browser protection.

LightGBMTF-IDFFastAPIChrome Ext.
Edge AI · Accessibility

Third Eye — Assistive Navigation

A fully on-device wearable navigation aid for visually impaired users on the Arduino Nicla Vision (ACM Winter School Edge AI Hackathon, IISc). Fuses ToF distance sensing and IMU-based fall detection with an INT8-quantized vision model (10× smaller, 0.80 accuracy), streaming real-time alerts over UDP to a Flutter/Streamlit UI.

Arduino NiclaINT8 Quant.ToF + IMUFlutter
Cloud · LAMP

Alumni Management System on AWS

A PHP/MySQL (LAMP) web application deployed on an AWS EC2 Ubuntu instance — configured security groups and SSH access, and managed provisioning and database import via PuTTY, FileZilla, and phpMyAdmin.

AWS EC2PHP/MySQLLAMP
Networking · Systems

Remote Desktop — Screen Sharing

A Python remote-desktop tool that streams a host's screen and relays remote mouse/keyboard control. Captured JPEG-encoded frames with OpenCV, evolved the transport from TCP to TLS-secured chunked UDP streaming (~20 FPS), and replayed input events with pynput across multi-threaded clients.

PythonOpenCVUDP/TLSpynput
